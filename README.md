# Simple CLI Expense Logger

makes use of SQlite for the database 

current functions:
- -f l - list all Expenses
- -f a - add an expense in the form of -n [name] -a [amount] -c [category]
- -f r - remove an expense with -i [id]
- -f u - update expense with -i [id]
- -f rt - reset table
- -f s - gives a summary of the amount of all transactions
